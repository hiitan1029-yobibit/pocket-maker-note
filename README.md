# いつも買ってるあのメーカー ポケット帳

買い物中に、いつも買っているメーカー・商品・サイズ・写真をすぐ確認するための小さなPWAです。

## できること

- 商品メモの追加、編集、削除
- 商品名、メーカー名、商品詳細での検索
- カテゴリーでの絞り込み
- 商品写真の登録
- 最後に買った日の記録
- ブラウザ内へのローカル保存

## データ保存について

登録した商品メモや写真は、利用しているブラウザのIndexedDBに保存されます。ログイン、クラウド同期、外部サーバーへの保存は行いません。

## 主な構成

- `src/`: アプリ本体
- `public/`: PWAマニフェストと公開用アセット
- `.github/workflows/`: GitHub Pagesへのデプロイ設定
- `vite.config.ts`: Vite設定
